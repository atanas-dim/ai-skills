# AI Skills

Reusable AI agent skills for coding workflows, shared as installable `SKILL.md` files for tools like Cursor, Claude, Codex, and other AI coding agents.

## Install

```bash
npx skills add atanas-dim/ai-skills
```

## Skills

- **Stepwise Implementation**: Implement an approved coding plan across multiple turns, completing exactly one meaningful step per turn with review, verification, and user confirmation before continuing.
